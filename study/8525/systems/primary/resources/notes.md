## Primary storage
Primary storage is a type of storage which can be accessed directly by the CPU. It is very fast compared to secondary storage as it needs to keep up with the speed of the CPU.

### RAM
RAM, or Random Access Memory, stores programs and data that are currently in use. Data can be written to and deleted from the RAM. RAM is volatile, which means that data is lost when the computer is turned off.

### ROM
ROM, or Read Only Memory, is used for starting up the computer, storing the BIOS. Data cannot be written to or deleted from the ROM.. It is non-volatile, therefore data is kept when the computer is turned off.

**Why does ROM need to be non-volatile?**
It stores the startup instructions and the BIOS. If it was volatile, it would not start again because it wouldn't know how to start.
