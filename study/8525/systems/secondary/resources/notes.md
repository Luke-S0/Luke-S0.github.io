## Secondary storage
Secondary storage is a type of storage used for storing applications, files, documents and the OS. It is used for long-term storage of data and is non-volatile, meaning that the data is kept, even when the computer is turned off.

### Characteristics
When justifying a secondary storage type, you will need to discuss some of the following characteristics.

| **Characteristic**       | **Definition**                                                                 |
| ------------------------ | ------------------------------------------------------------------------------ |
| **Capacity**             | How much data can be stored on the device?                                     |
| **Read/Write Speed**     | How quickly can data be read from or written to the device?                    |
| **Portability**          | How easy it is to move or carry the device.                            |
| **Durability**           | Can the device resist damage from drops and heat?              |
| **Reliability**          | Will the device work for a long time without loss of data? |
| **Cost**                 | How much does the device cost? (measured in price per GB)                     |

> Exam tip - do not write a device name when asked for storage **type**. For example, don't write *solid state drive* or *SSD* when asked for **type of storage**.

---
## Types of secondary storage
There are two types of secondary storage you need to know about for AQA 8525.

### Magnetic
There are a few examples of magnetic storage devices, such as hard drives and floppy disks.

### Solid state
Solid state is a common storage type, with examples of devices including SSDs, flash drives and SD cards.

## Evaluating secondary storage types

| **Term**             | **Magnetic**                                  | **Solid State**                                                    |
| -------------------- | --------------------------------------------- | ------------------------------------------------------------------ |
| **Capacity**         | ✓ - high capacity                             | ✓ - medium/high capacity                                           |
| **Read/Write Speed** | ✗ - slower than solid state                   | ✓ - fastest                                                        |
| **Portability**      | ✗ - often fixed into computers, such as HDDs. | ✗ - varies by device. SSDs are fixed but flash drives are portable |
| **Durability**       | ✗ - contains moving parts                     | ✓ - most durable                                                   |
| **Reliability**      | ✓ - very reliable                             | ✗ - limited read/write cycles                                      |
| **Cost**             | ✓ - cheaper price per GB                      | ✗ - more expensive price per GB                                    |
